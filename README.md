## 🔧 Step-by-Step — How to Upload to GitHub

**Step 1 — Create the repo**
- Go to github.com → click **New repository**
- Name: `kashan-analytics-portfolio`
- Set to **Public**
- Check **Add a README file**
- Click **Create repository**

**Step 2 — Upload your file**
- Click **Add file → Upload files**
- Rename your downloaded file to `index.html`
- Drag it in → click **Commit changes**

**Step 3 — Replace README**
- Click `README.md` → click the pencil ✏️ edit icon
- Delete everything and paste the README above
- Click **Commit changes**

**Step 4 — Add topics**
- On your repo homepage, click the ⚙️ gear next to "About"
- Paste the topics listed above
- Add your live Netlify URL as the website link

**Step 5 — Enable GitHub Pages (optional free hosting)**
- Go to **Settings → Pages**
- Source: **Deploy from branch → main → / (root)**
- Save → your site will be live at `kashananalytics.github.io/kashan-analytics-portfolio`
